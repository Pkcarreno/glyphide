# Semantic Code Naming

Applies semantic grammar rules, intent-based naming, and structural patterns (such as A/HC/LC: Action, High Context, Low Context) to variables, functions, and classes.

## When to Use

- **Writing new code**: Selecting descriptive identifiers that communicate intent upfront.
- **Refactoring**: Renaming vague, contracted, or overloaded identifiers.
- **Code reviews**: Evaluating naming clarity, positive boolean phrasing, and cardinality.

> Focuses on semantic meaning and intent. Typographical casing and formatting are handled by linters.
